# Universal Ubuntu Touch Builder

A cross-platform, evidence-driven toolkit for investigating, configuring, and building Ubuntu Touch ports for Android devices. Device support is determined by verified sources and tested porting paths, not merely by device detection.

## Project status

This repository is being established as a clean snapshot of AndroidBuilder's current development state. It has no inherited Git history. The first target is Sony Xperia R1 (G2199); the architecture is intended to support more devices through reusable profiles and build strategies.

## Safety

No image is considered bootable until verified on the exact device variant. Do not unlock, flash, erase, or repartition a device without a verified device-specific procedure and recovery plan.
